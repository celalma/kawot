# Kawot
Kawot is a website where you can find guides about videogames, turorials on how to mod your games and create mods, guides on how to create the videogame of your dreams and everything you need to start building your own website using HTML and CSS.
This repository contains the newer version of the website's HTML and CSS.

> [!NOTE]
